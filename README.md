# Annie — Personal Game Creator Site

A dependency-free, static cyberpunk portfolio homepage designed for inexpensive hosting.

## Run locally

Open `index.html` in a browser, or run a tiny local server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy cheaply

The site is plain HTML/CSS/JS, so it can be hosted free on GitHub Pages.

1. Create a GitHub repository, e.g. `annie-site`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. GitHub will provide the public URL.

Replace the placeholder project links, email address, social links, and project copy before launch.
